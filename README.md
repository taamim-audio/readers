# טעמים — מערכת פניות קוראים

טופס מועמדות לקריינות התורה באפליקציית טעמים + מסך ניהול פרטי לצוות.

- **טופס (ציבורי):** פרטי מועמד + העלאת דוגמאות קריאה בנוסחים שונים.
- **ניהול (`#admin`):** רשימת פניות, האזנה והורדה של הקלטות, סטטוסים, ייצוא לאקסל / ZIP.

גרסת הערכה ראשונה: הנתונים נשמרים בדפדפן (IndexedDB) — לא נשלחים לשום שרת.
